# Contributing to Awesome GEO

Thanks for your interest in helping make this list better!

## Adding a new entry

- **Alphabetical order** within each section.
- **Neutral tone** — no promotional language ("the best", "industry-leading", "revolutionary"). Describe what the tool does, not how it positions itself.
- **One sentence** for each entry, ending with a period.
- **Verifiable** — the tool / dataset / paper must be publicly accessible.

## Format

```markdown
- [Tool Name](https://example.com) — short neutral description ending with a period.
```

## What gets accepted

- Commercial GEO / AI-visibility platforms (verify the vendor exists and the URL works)
- Open-source tools and SDKs (must have a working repo, license, and at least a basic README)
- Public datasets and benchmarks (must be downloadable)
- Academic papers on GEO, AI search, brand mention extraction, LLM citation behavior
- Long-form articles and methodology guides
- Standards, conventions, and protocols

## What gets declined

- Affiliate links
- Marketing landing pages dressed up as "guides"
- Personal blog posts without substantive methodology
- Tools that haven't shipped
